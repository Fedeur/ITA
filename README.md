
###                                     IT Academy – Data Analytics

Repositorio con las entregas de los Sprints del curso de especialización en Data Analytics de IT Academy.
Cada carpeta contiene el PDF de la entrega, los scripts SQL y los recursos utilizados en cada Sprint.

## Contenido

Sprint 02

Resolución de ejercicios de SQL:
	•	creación de base de datos relacional
	•	consultas con JOIN
	•	subconsultas SQL

Sprint 03

Resolución de ejercicios de SQL:
	•	creación y modificación de tablas
	•	definición de claves foráneas
	•	inserción, actualización y eliminación de registros
	•	creación y consulta de vistas SQL
	•	consultas con JOIN
	•	subconsultas SQL

Sprint 04

Resolución de ejercicios de SQL:
	•	diseño y creación de una base de datos a partir de archivos CSV
	•	carga de datos desde archivos CSV
	•	normalización de relaciones mediante tablas intermedias
	•	consultas con subconsultas y funciones de agregación
	•	creación de tablas derivadas para análisis de datos
